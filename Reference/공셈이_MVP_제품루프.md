# 공셈이 — 제품 개발 루프 & 지표 체계

시공현장을 위한 AI 업무 파트너 '공셈이'의 제품 개발 루프(Problem → Learn/Pivot)와 지표 3종 체계 정리.
(레퍼런스: 공셈이 사업계획서·IR자료 기반)

## PART 1. 제품 개발의 기본 루프 — 공셈이

### Problem (문제 정의)
저는 수개월간 인테리어·건축 현장을 직접 따라다니며 시공자들과 함께 작업했고, 어디에서 시간과 비용이 새는지 직접 확인했습니다.
- 현장 기록의 취약성: 현장 노트가 물에 젖어 계산·기록이 유실되거나, 정작 필요할 때 노트를 안 가져와 이전 내역을 확인하지 못하는 일이 잦습니다. 반면 휴대폰은 누구나 늘 소지합니다.
- 계산·기록의 비효율: 면적·수량·로스율 계산이 계산기·엑셀·수첩에 흩어져 있어 매번 도구를 바꿔가며 작업하고 결과를 따로 옮겨 적어야 합니다. 장갑을 끼거나 양손이 바빠 입력 자체가 번거롭고, 눈대중으로 넘어가 과부족 발주·재작업으로 이어집니다.
- 소통·실측의 한계: 현장은 지역 방언·은어('헤베', '사메다' 등)로 소통해 기존 AI 앱은 질문을 잘 알아듣지 못하고, 실측은 수기나 외부 스캐닝에 의존해 비용·정확도에 한계가 있습니다.

### Hypothesis (가설 설정)
현장 규격(면적·치수)만 입력하면 KS 규격·표준품셈 기반으로 자재 수량과 견적을 자동 산출하고, 계산·기록·상담·일정을 하나로 묶어주면, 계산 시간과 오차·손실이 줄어 작업자가 계속 사용할 것이다.

### Metric (지표 결정)
가설 검증 지표로 '계산 → 작업기록 저장 전환율'과 '재사용(리텐션)'을 정했습니다. (자세한 지표 체계는 PART 4)

### Build (작게 구현 · MVP)
전 기능을 다 넣지 않고 핵심 자재 계산기 + 업무수첩(작업기록·메모)만 붙여 iOS·Android에 작게 출시했습니다.
- 제가 직접 인테리어·건축 시공현장에 나가 보고 들으며, 현장에서 실제로 쓰는 공식값을 반영해 기능을 구현했습니다.
- 계산·현장 데이터는 서버에 저장해 자료 유실 위험을 없애고, 오프라인에서도 사용 가능하도록 설계했습니다.
- 유입도 유료 광고 없이(광고비 0원) SNS 릴스로 작게 검증했습니다.

### Measure (데이터 확인)
- 누적 다운로드 약 1,000회+ (출시 1개월, 광고비 0원)
- 일평균 이용자 약 60~80명, 출시 후에도 현장 사용 지속
- SNS 릴스·영상 누적 조회 약 13만 회, 현재도 상승 중
- 작게 구현한 MVP만으로 실사용 수요를 검증

### Learn / Pivot (확대 · 수정 · 중단)
검증된 계산·기록 경험을 기반으로 단계적으로 확장 중입니다. (NOW → NEXT → FUTURE → BEYOND)

추가 완료
- 음성 AI 비서 '공담이' — 지역 방언·구어체·현장 용어까지 이해하도록 특화. 현재는 자체 LLM과 외부 LLM API를 함께 쓰는 하이브리드 형태이며, 하이브리드 라우팅·프롬프트 캐싱으로 질의당 원가를 낮추고, 방언 정규화·의도 분류·도구 선택 등 반복 작업을 자체 소형 LLM으로 전환해갈 계획입니다.
- 글로벌 다국어 버전 — 국내 외국인 근로자 수요 대응 (준비 완료)

진행 예정
- PC 버전 출시
- 홍보문구 자동 작성 — 네이버 블로그·인스타그램 등과 연계해 블로그 글·SNS 피드를 앱에서 자동 생성. 외부 서비스에 의존하지 않고 자체 제작하며, 초기에는 외부 API를 활용한 뒤 자체 구축형으로 전환 (기술 스택은 PART 3)
- AI 견적서·업무일지 자동 작성
- 세금계산서 발행 등 행정 업무 — 홈택스 등 정부 사이트에 따로 들어갈 필요 없이 앱 안에서 바로 처리 (정부 API 연계)

FUTURE · 개발 추진
- 자체 공간분석·도면화 기술 — 모바일에서 취득한 공간 데이터로 벽체·바닥·천장·개구부 구조·치수를 자동 인식하고, 실측 기반 2D 도면·3D 공간 모델로 변환. 기존 외주(도면 건당 평균 약 43만 원, 3D 투시도 장당 3~5만 원) 대비 시간·비용을 크게 절감.

BEYOND · 확장 목표
- 계산·기록에서 시작해 견적·거래·행정까지 하나로 잇는 종합 업무 플랫폼으로 확장
- 수출을 통해 나라별 규격 탑재·현지 언어 지원으로 해외 시장 확장 (미국 야드파운드법·ASTM, 유럽 미터법·EN/유로코드, 일본 JIS 등 지역별 단위·규격 반영)

## PART 2. 차별화 기능

- AI 자재 계산 — 음성과 텍스트를 모두 지원. 손이 바쁜 현장에서는 음성('공담이')으로, 그 외에는 텍스트로 계산·조회.
- 지역 방언 특화 음성 AI — '헤베·사메다' 같은 현장 은어·방언까지 인식(기존 AI 앱과의 결정적 차이).
- AI 홍보 지원 — 블로그·SNS 홍보문구를 자동 작성하고 게시까지 연계.
- 행정 업무 지원 — 견적서·업무일지 자동 작성과 세금계산서 발행을 앱 안에서 처리(정부 사이트 직접 방문 불필요).
- 마감재 시뮬레이션 — 시공 전 고객이 원하는 자재가 자기 집에 적용된 모습을, 현장 사진 + 자재 사진으로 이질감 없이 미리 보여줘 선택·거래로 연결.
- 자체 공간분석·2D/3D 자체 처리 — 외주 대비 대기시간·비용 절감.
- 글로벌 다국어 → 수출 확장 — 국내 외국인 근로자부터 해외 현장까지.

## PART 3. 자동 글쓰기 · AI 기술 스택 (홍보·콘텐츠 자동화)

외부 API로 빠르게 시작한 뒤, 자체 구축형으로 전환하는 2단계 로드맵.

### 1단계 — 외부 API 활용 (빠른 출시)
- 생성 모델: LLM API (Claude / GPT / Gemini)로 홍보문구·블로그 글 초안 생성
- 정확도 보강: RAG(검색 증강 생성)로 자사 데이터·자재 규격·공식값만 참조하게 해 할루시네이션(허위·과장) 방지 — LangChain / LlamaIndex
- 자동화 파이프라인: 키워드 → 초안 생성 → 편집·최적화 → 이미지 → 업로드까지 워크플로우 자동화 — n8n 등
- 게시 연동: 네이버 오픈 API(블로그 자동 포스팅), Instagram Graph API(비즈니스 계정·Meta 개발자 앱 승인 필요)

### 2단계 — 자체 구축형 (비용 절감·데이터 주권)
- 자체/로컬 LLM: Llama, Qwen 등 오픈소스 모델
- 서빙·운영: Ollama(간편) / vLLM(고성능 서빙)
- 도메인 특화: 시공·자재 도메인 데이터로 파인튜닝 + RAG 병행
- 효과: 외부 API 비용 부담 없이 자사 데이터 내재화, 공담이(음성 AI)와 동일한 자체 LLM 기반으로 통합

### 품질 관리 (중요)
- 완전 자동보다 'AI 생성 → 사람 검토 → 자동 게시'의 반자동 방식을 권장. 네이버 저품질 콘텐츠 필터를 회피하고 광고 규정(과장·허위 표현)을 지키기 위함.

## PART 4. 지표는 세 종류로 나눠서 본다

기능을 추가할 때마다 "이 기능이 목표 지표를 움직이는가?"를 묻습니다.

### Primary Metric (메인 지표) — 가설이 맞았는지 판단하는 핵심
- 계산 → 작업기록 저장 완료율 ↑
- 주간 재사용(리텐션) ↑

### Supporting Metric (보조 지표) — 함께 확인하는 지표
- 자재 계산 소요시간 ↓
- SNS 유입 → 설치 전환 ↑
- 무료 → 유료(PRO/프리미엄) 전환율 ↑
- AI 홍보문구 생성 → 실제 게시 전환 ↑

### Guardrail Metric (가드레일 지표) — 나빠지면 안 되는 안전선
- 자재 계산 오류율 ↑ 금지
- 음성(공담이) 방언·용어 오인식률 ↑ 금지
- AI 홍보문구의 과장·허위 표현 발생률 ↑ 금지 (광고 규정 준수)
- AI 결과 과도 수정률 ↑ 금지 (사용자가 AI 결과를 크게 고쳐야 한다면 품질 미흡 신호)
- 이탈률 ↑ 금지

> Guardrail이 없으면 서비스 지표(설치·사용)는 잘 나와도 엣지 케이스·예외 상황(오계산·방언 오인식·허위 홍보문구)에 대응하기 어렵습니다. 자재 수량을 다루고 자체 LLM으로 전환해가는 AI 제품에선 계산·생성 신뢰성이 특히 중요합니다.
